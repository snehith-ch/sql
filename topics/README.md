# SQL Server Learning Topics

Each topic folder keeps its related setup, revision notebook, and practice/workbook files together.

## Recommended Order Inside Each Topic

1. Run the setup SQL file if the folder has one.
2. Read the revision notebook.
3. Solve the practice/workbook SQL file.

## Folders

- `queries`: query lessons, combined query revision/practice, and older lesson workbooks.
- `views`: views setup, revision notebook, practice, and older workbook.
- `tsql_programming`: T-SQL variables and stored procedure intro.
- `stored_procedures`: stored procedure setup, revision notebook, practice, and older workbook.
- `udf`: user-defined functions setup, revision notebook, and practice.
- `indexing`: indexes setup, revision notebook, and practice.
